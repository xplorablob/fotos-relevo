# Marca de agua · Fotos de relevo

1. Sube un Excel a la carpeta `entrada/` (columnas FOTO, FECHA, HORA, RAZON SOCIAL, DISTANCIA y opcional DNI).
2. GitHub Actions descarga cada foto, le pone la franja gris transparente con letras blancas y la publica en `fotos/`.
3. El Excel con la columna `FOTO_MARCA_AGUA` queda en `resultados/` y el original pasa a `entrada/procesados/`.

Página: `https://USUARIO.github.io/fotos-relevo/`
